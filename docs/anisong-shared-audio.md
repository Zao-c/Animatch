# 公共曲单、公共音频池与试听降级

## 使用

1. 在 `/anisong` 创建个人曲单，上传有权公开使用的音频，或从网易云、HTTPS 音频直链准备歌曲。保留动画、季度、类型和封面。
2. 需要备用源时，在每首歌的「匹配 iTunes 备用源」中选择地区并确认歌手、专辑和版本。也可直接从 iTunes 找歌加入曲单。iTunes Search API 不需要用户填写 API key。
3. 在曲单中的「发布为公共曲单」确认音频可公开使用，然后发布。服务器下载可用音频，按内容哈希去重，保存到公共音频池。iTunes 试听文件不会下载入池。
4. 其他人在公共曲单列表选择「开始 / 继续我的对决」。只需 AniMatch 账号保存个人进度，无需创建者的网易云账号。每个人的对决和 Tier List 独立。
5. 在音源设置选择「公共音频池优先」或「iTunes 优先」，可关闭自动切换。偏好只保存在当前浏览器。

保存个人草稿不会自动公开音频。已发布曲单更新时生成新版本；已有玩家保留开始时的歌曲版本与进度。下架公共曲单、删除创建者草稿不会删除其他玩家正在使用的公共音频或共享封面。

## 播放与失败处理

- 按需加载当前歌曲，不预下载全部曲单。每次投票成功后，只为下一组公共池歌曲请求媒体元数据，最多两首；不预取私人上传、网易云或 iTunes。设备启用省流量模式或网络为 2G / slow-2G 时跳过，并在换页、曲单变更或组件卸载时取消。支持单播放器、Q/E 试听、左右封面及按钮投票、方向键投票、暂停、重播、选段和共享音量。
- 首次加载或解析超过8秒、播放中持续卡住6秒、接口或媒体报错时，自动切换已关联的备用源一次。两种音源都失败时停止并显示原因。
- iTunes 从平台提供的片段开头播放，最长30秒；切换后从对应来源的片段起点重播。不会自动猜测同名歌曲的版本。缺少备用匹配的歌曲无法双源降级。
- 选择、试听、切换音源互不代替；只有明确投票才计入比较。迟到的旧请求不会重新抢占播放。
- HTTP 地址也可创建投票及批量导入编号，不依赖只在安全上下文可用的 `crypto.randomUUID()`。
- 相同歌曲在同侧继续参加下一轮时保留媒体元素及已缓冲内容；录音来源或选段改变时重新加载。

## 缓存、大小和音质

- **服务器公共池**：部署配置 COS 后，原始音频按 SHA-256 写入 `AniMatch/audio-pool/`，有效压缩的 MP3 副本写入同前缀下的 `preview/`；播放器优先从 COS 公网地址读取试听副本。相同文件哈希复用一份；原始音频保留供回退。未配置 COS 的本地开发仍使用磁盘目录。
- **用户设备**：公共音频响应允许浏览器 HTTP 缓存：`public, max-age=31536000, immutable`，支持 HEAD 与字节 Range。浏览器决定缓存哪些已请求内容及何时清理，不能保证完整下载或离线播放。
- **私人上传**：受账号保护的文件使用 `private, no-store`；播放器可在当前媒体元素中缓冲，页面关闭后不保证保留。
- **第三方直连**：网易云、iTunes 由浏览器直连平台音频，缓存行为由平台响应头及浏览器决定。应用只短期复用解析结果，不把第三方临时 URL 当作永久文件。
- `localStorage` 只保存音量及来源偏好，没有歌曲二进制。未使用 Service Worker、Cache Storage 或 IndexedDB 实现离线音频下载。
- 公共曲单发布时保留原始音频，并尝试生成 128 kbps MP3 试听副本；仅当新文件至少缩小 10% 才额外保存，否则播放器复用原音频。播放器优先使用试听副本，原始文件继续保留供回退。网易云请求 `standard` 质量；实际质量和试听权限以平台返回为准。
- 原始单文件上限20 MiB，公共池默认5 GiB，配额统计原件和额外试听副本合计，通过 `ANISONG_PUBLIC_AUDIO_QUOTA_BYTES` 配置。20 MiB 是上限，不代表每首歌大小。
- 按128 kbps计算，30秒约480 kB，90秒约1.44 MB；320 kbps则分别约1.2 MB与3.6 MB。试听时长限制只控制播放，不会把完整源文件物理裁剪成小文件，浏览器可能预取超出试听片段的数据。

文件变小可减少传输时间与流量，但广州 COS 到用户的跨网链路仍可能导致卡顿；此版本没有 CDN，也不能保证所有网络条件都不卡。

## iTunes 使用条件

元数据与试听地址由 Apple Search / Lookup API 获取，官方商店链接和 iTunes 来源标识随播放器显示。Apple 试听音频从平台直接流式播放，不保存到公共音频池；下载器也拒绝 Apple 媒体域名。

Apple 对试听内容有推广用途、关联商店链接、流式播放等限制；音乐对决的独立娱乐用途可能不符合其条件。来源标识和链接不能单独证明用途合规，站点运营者需要确认适用条件。参见 [Apple Search API](https://performance-partners.apple.com/search-api) 及 [Search API 结果与使用条款](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/iTuneSearchAPI/UnderstandingSearchResults.html)。

## 运维

新增 `SongTemplate`、`SongAudioAsset` 和 `SongBoard.templateId/templateRevision`，生产启动执行增量迁移 `20261030090000_shared_song_templates`。COS 音频迁移增加 `SongAudioAsset.storageProvider`；新入池对象按内容哈希重试安全写入，并仅对这个对象设置 `public-read` 与一年 immutable Cache-Control，不修改存储桶级 ACL。部署只更新应用，保留网易云服务：

```sh
docker compose --env-file .env.production -f docker-compose.prod.yml up -d --build --no-deps app
```

生产音频凭据用独立 `ANISONG_COS_*` 变量，避免覆盖图片使用的 AniMatch COS 配置；桶与对象前缀须对应授权。备份需同时覆盖 PostgreSQL、COS 音频前缀、`anime_uploads`、私人音频和网易云凭据卷。公共文件不随曲单删除自动回收；当前没有自动垃圾清理及存储管理 UI。多实例入池仍需补充分布式配额协调。

外链入池只允许公开 HTTPS 域名，解析并固定公网 IPv4，每次跳转重新校验地址，限制重定向、大小及下载时间。不把平台 Cookie、私有文件路径、原始外链、创建者投票和手动档位复制到公共模板。

## 试听副本与预加载

- 原件继续保存在 COS；发布公共曲单时使用 FFmpeg 生成 128 kbps、44.1 kHz 的 MP3 副本，只有至少减少 10% 才额外存储。播放器先读副本；压缩无收益或格式不支持时使用原件。
- 试听副本使用版本化对象键，便于未来编码策略变化时绕过 immutable 缓存。生产 Docker 镜像安装 FFmpeg；原有公共资产可通过 `pnpm anisong:audio:previews` 校验哈希并补齐副本。
- 成功投票后，为下一对公共池歌曲创建最多两个 `preload="metadata"` 音频元素，复用浏览器媒体缓存。不会预下载整首歌曲，也不会预加载私人上传或第三方源；系统省流量模式及 2G 网络跳过预加载。切换页面、编辑、重新载入或离开页面会释放预加载元素。
- 预加载是浏览器提示，浏览器可因省流、数据或缓存策略减少请求；压缩音频可降低流量，但当前仍直连广州 COS，未配置 CDN。

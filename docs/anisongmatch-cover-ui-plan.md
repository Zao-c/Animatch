# AnisongMatch 封面与交互优化

目标：音乐对决同时呈现封面和可播放的音乐，沿用 AniMatch 的布局和交互习惯；修复保存、试听和分享中的边界问题。

## 本轮实施

| 优先级 | 问题 | 实施方案 | 验收 |
| --- | --- | --- | --- |
| P0 | 对决只有音符，无法辨认专辑或动画 | 歌曲支持封面上传/HTTPS地址；曲单、对决、Tier List、分享和PNG统一携带封面 | 上传、替换、清空、坏图回退；桌面和手机实测 |
| P0 | 音乐页与原版左右卡片样式差异较大 | 复用 `MatchArena`；相同边框、圆角、青色选择按钮和封面点击选择，播放器独立放置 | 封面不溢出、文字截断有完整标题、左右卡片对齐 |
| P0 | 快速试听时未完成的播放请求可能干扰下一首 | 给播放意图加版本标记，取消的请求不得重新抢占播放；区分加载、暂停和出错状态 | 延迟音频响应、左右快速切换、片段结束后重播 |
| P1 | 替换封面可能破坏旧分享 | 图片使用不可变地址；现曲单与已发布快照共同决定引用，最后一个引用撤销后回收 | 替换后旧快照仍可见旧封面；更新/撤销快照后回收 |
| P1 | 外链封面可能因跨域限制导致整张PNG导出失败 | 有界并发加载、超时和占位回退；导出后明确提示未载入封面 | 成功图片进入PNG，失败封面不阻塞下载 |
| P1 | 刷新回到曲单，且左右题目可能交换 | 视图写入URL；同一对决历史使用确定的配对随机序列 | 刷新保留视图和左右顺序，撤回恢复原题 |
| P1 | 内部导航可能丢失未保存表单 | 复用原有未保存保护；加载新版本不重建当前编辑表单；操作中禁止切换页签 | 取消离开仍保留字段，冲突重载保留待提交文件 |
| P1 | 手机播放器文字挤压、选择按钮不齐 | 压缩表头、允许播放状态换行、等高标题/信息块、按钮贴底；增加折叠音量控制 | 320/390/768像素宽度无横向溢出，触控操作可达 |

## 后续路线

1. 确定元数据来源后，接入季度 OP/ED 曲库，带动画关联、封面和去重标识；导入前确认候选歌曲，保留手动修正。
2. 确定 iTunes/网易云的服务和使用条件后，增加曲库搜索适配器；区分歌曲页面、试听音源和失效音源，接入限流与可用性提示。
3. 在真实曲单体验反馈基础上，加入批量歌曲导入、音频内嵌专辑图提取和试听起点快捷设置；元数据提取失败时保留手动输入。
4. 积累真实使用数据后再扩展多人公开音乐曲单与社区榜，保持个人对决与社区投票独立。

第三方数据接入继续遵循本次会话已有约定，等待用户确定 API 方案。本轮 P0/P1 已实施，验证结果见下方。


## 存储与兼容

- `coverUrl` 为可选字段；旧曲单和旧分享无需数据库迁移，自动显示无封面状态。
- 封面通过 Sharp 解码并统一转为最长边800像素的WebP，限制5 MB输入和2000万像素，不接受SVG或伪造图片。使用现有 `anime_uploads` 持久化卷；音频保持私有。
- 图片地址不可变，旧分享保留原图。删除曲单、移除图片、更新/撤销分享时，清理已无引用的本地封面；失败的上传也会清理文件。
- 上传封面沿用原站公开图片地址的访问方式，不公开音频。外链封面由浏览器加载；如图源限制跨域导出，可改为本地上传。
- 补充修复：仅修改封面且未提交音频字段时保留原音频；上传本地文件可以替换已有音频直链。
- 音量为浏览器偏好，换题后保留；在禁止浏览器存储时仍可播放和调音量。

## 验证结果

- 音乐功能、共享页头、原有对决布局及离开保护的定向测试37项通过；TypeScript、ESLint、生产构建通过。
- 真实浏览器检查：上传/预览/移除封面，刷新保持对局与视图，延迟音频响应时快速切换左右，暂停与重播，片段结束，音量记忆，撤回恢复原题，封面PNG导出，匿名分享访问，旧快照保留封面、更新/撤销后的清理，失败上传不遗留文件，坏图占位和导出回退。
- 320、390、768像素宽度无横向溢出，左右对决卡片等高。桌面、手机、榜单及PNG截图位于 `output/anisong-covers/`（测试封面和测试音频，不使用真实音乐素材）。
- 构建后的本机服务再次通过浏览器检查：封面显示、音频播放、带图PNG导出、修改其他字段保留音源、上传音频替换原有直链。
- 扩大回归时发现原有 `season-match-ui.test.ts` 6项、`match-empty-state-ui.test.ts` 1项失败。在修改前提交 `0934aea` 的隔离目录复跑，得到相同7项失败（14项通过）：断言引用旧文案、旧变量名/函数签名和旧队列阈值。本轮未更改这两个测试文件及对应动画页面，也未把这些失败计入通过数量。后续应将这些旧源码断言迁移为行为测试。
- 本轮没有执行生产部署或生产数据迁移，继续使用独立测试库和本机3129端口预览。

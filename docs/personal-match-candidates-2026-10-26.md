# 个人 Match：本轮对决范围

日期：2026-10-26（北京时间）\
状态：已于 2026-10-26 21:33（北京时间）部署并执行迁移。线上版本及检查结果见本文部署记录。

## 1. 本次解决的问题

个人 Match 原来只能在当前对局逐个标记“没看过”，缺少批量控制接下来比较哪些作品的入口。直接批量改 `isHidden` 会影响 Tier 榜单，而且撤回按投票记录重算时会覆盖隐藏状态。

新增“本轮对决范围”，将暂时不出题的设置保存到本轮记录。它适合集中比较部分作品，并保留已有评分。

| 操作 | 对决队列 | 历史评分 / Tier | 撤回与重开 |
| --- | --- | --- | --- |
| 在范围面板暂停作品 | 普通 Match 不再出题 | 保留，不冒充没看过 | 撤回不清空设置；新一轮恢复默认范围 |
| 在范围面板恢复作品 | 恢复出题资格 | 保留 | 不产生投票记录 |
| 对局中标记没看过 | 从本轮隐藏 | 按原规则不进入本轮 Tier | 可以撤回上次选择；不提供任意历史“没看过”批量反转 |
| 撤回上次选择 | 重新读取候选与队列 | 从有效历史重算 | 本轮范围单独保留 |

范围只约束普通 Match。已有的校准流程保持原规则。稳定度、Tier 目标与累计进度仍按本轮未隐藏作品计算，缩小范围不会自动宣告榜单完成。

## 2. 交互

- Match 顶部、没有可用组合和补充失败页面都有入口；有暂停作品时显示数量。
- 搜索名称与别名；每页 24 部；切换分页和搜索保留选择。
- 支持全部 / 参与 / 暂停 / 没看过四种状态筛选。
- 支持恢复全部可选作品、清空后重选、选择本页、取消本页。
- 已标记没看过的作品显示原因并禁用勾选；误点可关闭面板撤回上次选择，空队列页也补上撤回入口。
- 可选作品至少有两部时，保存至少保留两部；不足两部时允许保存剩余可选范围，并明确仍不能生成对局。
- 未保存调整关闭时提示；支持 Escape；关闭并同步后将焦点返回范围入口。
- 保存失败保留选择；版本冲突提示重新加载，不静默覆盖其他页面的设置。

## 3. 数据与请求

- 新增 `PersonalRun.matchExcludedAnimeIds`，默认空数组，旧榜单和新一轮默认不额外暂停作品。
- 新增 `GET /api/pools/:poolId/runs/:runId/candidates`，返回当前账号的作品、没看过状态、暂停名单和版本摘要，响应不缓存。
- 新增同路径 PUT，检查预期账号、所属番组 / 轮次、访问权限及有效作品集合。
- 保存事务校验作品集合、没看过状态与暂停名单的摘要。完全相同的目标范围可重试；有并发变化时返回冲突。
- 不写全站观看记录，不改评分、不改 `isHidden`，不生成伪投票。
- 新增普通投票在事务内检查最新对决范围；其他页面留下的旧卡片不能继续提交已暂停作品。原编号已保存的票优先确认，保留原有重试语义。
- 打开面板即让旧补充请求失效，暂停投票快捷键与后台补队列；关闭或保存后清空旧队列重新获取。
- 修复过期补充请求的结束回调干扰新请求状态，以及过期进度响应回写页面的问题。
- 候选不足两部时停止自动补队列，提供调整范围 / 撤回入口。
- 番组后续新增作品默认参与；没有实时跨标签页推送，其他页面会在下一次读取时同步，服务端拒绝过期投票。

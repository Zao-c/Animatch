## 1. 定位到的问题与修复

| 问题 | 修改 |
| --- | --- |
| 投票、跳过、没看过、恢复作品各自控制状态，快速操作可能交错 | 增加同步操作锁；加载、提交和换组期间统一禁用相关入口；快捷键同样检查锁 |
| 不确定的投票失败后仍可换获胜方或私心票设置 | 保留完整原请求和原提交编号，只能重试原票；未确认前禁止换组、恢复作品和调整候选 |
| 获取新批次失败后可能还留着上一票的卡片 | 请求新队列时清空已消耗批次；失败后明确重新获取，避免把已投组合当成下一票 |
| 切换赛季后旧异步请求可能回写页面 | 页面按番组 / 赛季重新挂载；加载请求有代次检查，卸载后的响应不更新状态 |
| 投票成功后要等约 600ms，票数往往等换批才更新 | 反馈等待缩短为约 180ms，减少动态效果偏好下不额外等待；每票成功后使用服务器返回的总票、每日票和私心票计数，避免重试时重复递增；换批再读取赛季状态 |
| 浏览器按赛季存储“没看过”，与服务器记录取并集 | 移除该缓存读写，只使用当前账号的服务器隐藏记录，避免不同账号混用和已恢复作品再次被旧缓存排除 |
| 输入法 / 组合键可能误触投票，Shift 还会切换私心票 | 忽略输入法组合过程、长按重复和 Ctrl / Meta / Alt 组合；私心票快捷键保留 B |
| 已保存的投票在赛季截止后重试，可能先被时间校验拒绝 | 服务端先确认同一编号是否已提交，再对新票校验时间与额度；重试核对原作品、获胜方和票种，不接受不同内容复用同一编号 |
| 账号在另一个页面切换后可能使用旧页面内容提交 | 投票和候选修改可携带预期账号，服务端拒绝账号不匹配的请求 |

### 续改：刷新恢复与票数同步

- 发送赛季票前，将原作品、显示名称、获胜方、私心票设置和提交编号写入 `sessionStorage`，按账号 / 番组 / 赛季隔离。
- 同标签页刷新后，先显示原票确认卡片，不自动提交，也不先生成新的对局。只有点击“确认原投票并继续”才重试原编号。
- 确认入口独立于新投票额度和赛季时间判断；即使没有剩余票或赛季截止，也能向服务器确认此前是否已保存。新票仍受正常额度和时间校验。
- 网络中断或不确定失败后保留原记录，暂时锁定换组、修改候选和新投票；恢复请求被拒绝时也保留，供查看榜单后处理。
- 已确认成功或首次提交被明确拒绝后清理本地记录。清理时核对提交编号，避免迟到的旧响应清掉新请求。
- 增加“清除本地记录”及确认说明：它不会撤销服务器投票，也不能取消服务器仍在处理的请求。清除后重新读取赛季状态。
- 待确认时，刷新 / 关闭标签页使用浏览器离开提示，站内普通链接使用原票待确认提示。浏览器前进 / 后退和程序跳转不保证显示提示，恢复记录仍保留。
- 存储写入失败时明确提示只能在本页重试；读取失败时不自动重发，先查看榜单再清除异常记录。记录清理失败同样提示，不伪装成已清理。
- 服务器投票响应增加实际计数 `usage`，正常保存和重复确认均重新读取当前累计、每日和私心票用量。页面不再依据历史投票序号或本地 `+1` 推断剩余票数；回顾入口也使用累计票数。
- 新票的计数读取发生在原写入事务内，不额外请求完整赛季榜单；恢复确认后再同步候选和赛季详情。

个人 Match 已有恢复保持原实现，自由排榜原生封面拖拽保持不变。

## 2. 选择熟悉的作品

赛季 Match 顶部新增可选入口，无需先填完清单才能开始投票。

- 清单按当前服务器候选状态勾选，不推断用户的实际观看历史。
- 支持名称 / 别名搜索、24 部一页、跨页保留选择、选择全部、清空后重新选、选择 / 取消本页。
- 显示已选数量和将隐藏数量，至少保留 2 部。
- 应用后，未勾选作品从当前账号的本赛季候选中隐藏；可重新打开面板恢复部分作品，或使用“恢复已排除作品”恢复全部。
- 不消耗票数，不删除已有投票，不修改全站观看记录或个人 Match 的候选状态。
- 有未应用调整时，关闭 / 重新加载清单先提示；保存失败保留当前选择；支持 Esc 关闭，关闭后回到入口焦点。
- 列表保存采用一次事务，包含恢复已选和隐藏未选。校验作品集合与打开时的隐藏记录，避免用过期清单覆盖其他页面的修改。
- 相同选择已应用时，重试返回当前结果；重复标记同一作品隐藏也不会重复增加隐藏次数。
- 保存期间禁止再次提交；关闭面板重新同步服务器候选状态。

这是赛季候选筛选功能。后续个人自由对决已单独实现“本轮对决范围”，已部署，见 [个人 Match 范围优化](personal-match-candidates-2026-10-26.md)。

- 原生拖拽与鼠标手势扩展的冲突仍未实测，本轮未改变直接拖动封面的行为。

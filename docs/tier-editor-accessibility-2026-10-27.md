# 个人 Tier 排序操作优化（2026-10-27）

状态：已改代码，尚未部署。

## 已修复的问题

| 问题 | 处理 |
| --- | --- |
| 桌面样式完全隐藏分档和前后移动控件，只能拖动 | 编辑卡片增加“调整位置”按钮；支持鼠标点击、Tab、Enter / Space 展开，Escape 收起并返回按钮 |
| 跨档移动会重新挂载卡片，键盘焦点丢到页面 | 移动后定位同一部作品的可用控件；原控件隐藏或已禁用时选择可用入口 |
| 作品移到其他档位后，不容易接着操作 | 操作区滚动到可见范围，预留吸顶工具条空间；状态提示显示目标档位 / 顺序 |
| 手机未保存提示与按钮挤在同一行 | 手机工具条上下排列，保存 / 取消按钮并排铺开；长作品提示最多显示两行，先显示目标位置 |
| 拖回自己时，作品可能意外移到本档第一位 | 自身放置按无操作处理 |
| 取消拖拽后可能残留来源，后续拖入别的东西误改排序 | 拖拽结束后清理来源；操作控件不启动卡片拖拽 |
| 保存期间看起来仍能拖动或调整顺序 | 同步禁用原生拖拽、位置按钮、下拉框与前后移动按钮 |
| 导出模式可能渲染编辑控件 | 导出模式不渲染位置调整控件，也不允许启动拖拽 |

## 交互方式

- 保留直接拖动封面的原生操作。桌面“调整位置”默认收起，只增加一行按钮；封面尺寸与比例不变。
- 手机仍直接显示分档下拉框和前后移动按钮，无需额外展开。
- 跨档后，桌面焦点回到新位置的“调整位置”按钮；手机焦点留在新位置的分档下拉框。
- 档内前后移动后优先保留原按钮焦点；到达边界后跳到同一卡片的可用控件，避免停在已禁用按钮上。
- 操作提示通过 `role="status"` 更新，保留“未保存到账号”的状态说明。

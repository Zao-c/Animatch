# 个人 Tier 导出与分享（2026-10-27）

状态：已改代码，尚未部署；无需数据库迁移。

## 已明确的行为

| 操作 | 使用的内容 | 是否保存到账号 | 是否创建公开链接 |
| --- | --- | --- | --- |
| 导出图片 | 点击导出时页面上的排序，包含未保存调整与当前分层名称 | 否 | 否 |
| 分享未修改的榜单 | 当前已保存排序与当前分层名称 | 不重复保存 | 显式确认后创建 |
| 分享未保存排序 | 先保存本页排序，再用保存响应中的版本创建快照 | 是，按钮明确写明“保存并创建公开链接” | 保存确认成功后才请求创建 |
| 复制之前的链接 | 生成该链接时的固定快照 | 否 | 不创建新链接 |
| 按当前榜单重新生成 | 重新确认当前内容；有排序修改时先保存 | 有未保存排序时保存 | 新建固定快照，旧链接保留原内容 |

## 已修复的问题

- 原来导出使用未保存排序，分享却静默使用服务器旧排序。现在导出入口说明范围，分享确认区明确是否先保存。
- 原来公开分享可能读到其他页面刚更新的排名。Tier 响应现提供 `shareVersion`，分享接口校验页面确认的版本；摘要覆盖展示作品、排序、分层配置、评分及比较计数，普通投票变化也会触发重新确认。
- 保存排序仍使用独立的 `manualTierVersion`。两种版本承担不同操作，普通评分变化不会因此无关地阻止保存手动排序。
- 保存失败或结果未确认时保留当前草稿，不继续请求创建公开链接。保存成功但分享失败时保留保存结果，重试只创建分享，不重复保存。
- 分享冲突时提供“重新载入后确认”，不会自动发布新版本；重新载入前若有未保存排序，需要确认丢弃。
- 分享结果展示快照时间。继续编辑排序或分层名称后，说明旧链接仍是之前内容，提供复制旧链接及按当前内容重新生成入口。
- 分享创建期间锁定排序、拖拽与配置操作。确认区支持 Escape 取消及焦点返回，成功后焦点到复制链接按钮，失败后回到可阅读错误的确认区。
- 本地导出使用自定义作品名称等展示信息；导出与公开快照的作品数按实际展示项统计，对决数统一使用有效对决。
- 修复实际 PNG 标题区统计换行后被裁切的问题。导出失败保留排序并提供重试，不要求先刷新页面。

## 边界

- 旧链接内容固定；本页根据本地编辑或重新加载后的版本变化提示差异，不提供跨标签实时同步。其他标签页投票或编辑会在分享版本校验时发现。
- 保存和分享是两个顺序请求。分享失败不会撤销已经成功的排序保存。
- 分享响应丢失时不把结果说成“确定未创建”。该接口不承诺重试复用同一条链接。
- 创建分享需要 `expectedVersion`；发布后，旧标签页缺少版本时会收到重新载入提示。已有分享的读取不需要此参数。

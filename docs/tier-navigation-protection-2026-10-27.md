# 排榜离开保护（2026-10-27）

## 已修改

- 个人自动 Tier 与自由排榜共用 `useUnsavedChanges`。存在未保存修改时，在支持取消导航的浏览器中，后退和前进会先确认；取消后地址和编辑区保留。
- 不额外插入历史记录，不修改 Next.js 保存的路由状态，保存或卸载编辑页后移除监听器。
- 只改变锚点的历史跳转不提示。新标签页、下载及邮件等非网页链接不触发自定义离开提示。
- 普通网页链接确认离开后，在本次链接导航的关闭事件中跳过重复提示；之后的其他离开仍受保护。
- 个人 Tier 的“开始校准”属于按钮触发的程序导航，补充未保存确认；取消时不创建校准会话。

## 浏览器边界

- 使用 Navigation API 的 `navigate` 事件，并检查事件是否允许取消；参见 [HTML 导航规范](https://html.spec.whatwg.org/multipage/nav-history-apis.html#the-navigate-event)。不对已取消或不能取消的导航显示无效确认。
- 完整页面离开和刷新继续使用浏览器原生 `beforeunload` 提示。旧浏览器没有 Navigation API，或浏览器不允许取消当次导航时，SPA 后退 / 前进依靠原有标签页草稿恢复，不承诺能阻止跳转。
- 草稿使用 `sessionStorage`，尚未保存到账号；关闭标签页、浏览器存储不可用、跨设备访问不具备相同恢复保证。

## 检查

- `tests/unsaved-changes-guard.test.ts` 的 6 项行为测试通过，覆盖拒绝 / 同意离开、查询与锚点、完整页面离开、不可取消导航、卸载清理及无 Navigation API 的降级。
- 本地 Next 开发页与 Chromium 浏览器检查通过：取消后退和前进后保留 URL、编辑与暂存，历史记录长度不变；锚点跳转不提示；确认离开后返回可恢复草稿；保存后离开不提示；普通文档链接只确认一次；取消校准不发出创建请求。
- 另使用普通 HTTP 测试域名验证 Navigation API 可用，取消后退仍停留在编辑地址；此检查未访问生产服务。
- 浏览器检查使用模拟 API 和本地页面，没有生产写入。尚未在 Safari、Firefox 或真实移动设备验收。
- TypeScript、改动文件 ESLint 和差异格式检查通过。
- 无数据库迁移，尚未部署。

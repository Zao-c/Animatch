# AniMatch 界面统一与栏目区别

## 命名

年度活动暂定“AniMatch 年度动画大赏”，具体奖项为“年度最佳动画”“年度最佳 OP”等。此前提供的工作簿属于其他群的参考，不使用其活动名称作为本站品牌。活动组织者后续可自定义活动标题和趣味奖项。

## 共用基础

- 两种 Match 使用同一个内容宽度、对决卡片、封面高度、标题区、选择按钮和辅助操作组件。
- 页头统一顺序：模式与状态、返回入口、番组/赛季名称、一句话目的、榜单/设置。
- 按钮用词和快捷键一致：←/→ 选择左右，↓ 跳过，1/2 左右没看过，0 都没看过。赛季保留旧的 3 键作为兼容入口，界面只提示 0。
- 图片和选择按钮都可点，标题在图外，长标题限制两行、完整信息可展开。详细 Elo 不抢占首屏。
- 不通过只改标题区分栏目；以用户任务、可用动作、进度含义和内容构图共同区分。
- 保持字体、圆角、边框、按钮高度和反馈行为一致。状态同时用文字表达，不仅依赖颜色。

## 栏目差异

| 栏目 | 主要任务 | 信息重点与布局 |
| --- | --- | --- |
| 个人自由对决 | 逐步整理我的偏好 | 青色标识、个人进度、不限票数、“差不多”和撤回/重开；统计位于作品下方 |
| 赛季投票 | 在活动期内贡献我的选择 | 琥珀色标识、活动状态、剩余票数、独立私心票；不显示不存在的平局功能 |
| 自由 Tier List | 手动排列作品 | 排榜画布与待排作品栏，突出保存、撤销、导出 |
| 社区榜 | 看结果、找分歧与遗珠 | 排名列表或分层图，侧栏/独立分页展示群友对照，说明不压过作品 |
| 年度动画大赏 | 提名、现场投票、揭晓 | 提名册、候选展示、节目单、主持台和全屏揭晓；不套对决布局 |

## 本次修订

增加 `MatchPresentation.tsx`，两种 Match 共用展示基础；保留各自数据接口与计分流程。赛季的 ↑ 私心票快捷键取消，使用明确的 B 键（保留 Shift 兼容）。阶段小结移到对决后，减少投票前的阅读负担。私心票剩余与用户操作语义继续明确展示。

## 后续页面验收

桌面与手机分别检查：首屏是否能看到主任务；选择按钮是否对齐；是否有横向溢出；长标题和加载失败能否处理；相同按键是否含义一致；模式特有操作是否能被识别；辅助面板是否遮挡主操作。新栏目先复用基础组件，再定义独有的内容结构。

# 用户体验与榜单展示改进

## 已实现

- 手机导航固定分成品牌/账号、三个主要入口两行，增加键盘跳转主内容入口，小按钮在手机上至少 44px 高。
- 首页减少数据来源和导出格式术语，用用户能直接理解的说明介绍对决与榜单。
- 番组列表保留搜索主入口，状态、视图和排序收入可展开区域，收起时仍显示当前筛选。
- 个人 Tier List 合并重复标题，将进度指标和详细说明放入说明区；初始估计警告和公开分享确认保留。
- 每档作品自动换行，手机按屏幕宽度显示 2–3 列，桌面自动填充；展示每档数量，保留拖拽和手机移动控件。
- 导出显示封面准备数量、图片生成阶段及完成提示，失败仍明确报告，避免下载缺图结果。
- 修复个人导出和历史快照展示的地址优先级：快照已经确定的 `coverUrl`（COS 或自定义封面）优先于旧 `imageLargeUrl`。旧快照没有 `coverUrl` 时仍使用原有候选字段。

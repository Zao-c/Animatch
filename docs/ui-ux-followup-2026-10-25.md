## 行为边界

### 导入

- UI 提交时总是发送选中的作品 ID；这些条目已由预览流程写入作品库。
- 不再按发生变化的上游筛选结果重新裁剪选择。创建事务确认条目没有删除且属于可导入的目录来源。
- 旧调用方若不传选择列表，仍保留先生成候选再创建的行为。
- 本轮没有加入“创建番组”请求本身的幂等键。若创建已成功但响应丢失，再次创建仍有重复番组风险，需要单独处理。
- U02 的服务端取消、整批请求截止时间和分页进度反馈仍未实现。

### Match

- 处理的是当前页面内同一票的重试。服务端已有 mutation ID 去重，本轮让客户端正确复用。
- 参数错误、认证失败等明确拒绝的响应允许用户重新选择；网络错误和不确定的服务器错误保留原请求。
- 待确认请求目前不跨刷新持久化。本轮也没有改造赛季 Match；其现有代码已经按对决 / 获胜方保存重试 ID，但完整操作互斥仍需检查。

### 排榜恢复

- 使用 `sessionStorage`，支持同一标签页刷新、导航离开再返回；不承诺关闭标签页或跨设备恢复。
- 暂存不等于保存到账号。页面继续提供未保存提示和原有离开确认；用户仍需手动保存。
- 发现暂存时先让用户选择恢复或放弃，再开放编辑；不会悄悄覆盖服务器内容。
- 自由排榜通过服务端 revision 检查保存冲突。恢复旧版本时先确认，再使用当前版本号作为后续保存基础。
- 个人 Tier 恢复前校验作品集合、档位及旧快照；若作品 / 档位不再兼容，保留暂存并提示无法直接恢复，不静默丢弃部分排序。
- 10 月 27 日：个人 Tier 服务端保存已增加版本比较，冲突时保留本地草稿并明确确认后才可丢弃重载，见 [个人 Tier 冲突保护](personal-tier-conflict-protection-2026-10-27.md)。可取消的 SPA 后退 / 前进导航现已增加确认，完整页面仍使用浏览器提示，兼容边界见 [排榜离开保护](tier-navigation-protection-2026-10-27.md)。
- 暂存失败会显示提示；不得把存储失败描述为已经保存。
